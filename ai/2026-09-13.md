> **Stealth startup Accomplish** (founded by Or Hiltch, Amit Avner and Guy Zipori) publicly disclosed a family of **Configuration-Based Sandbox Escape (CBSE)** vulnerabilities affecting a full cross-vendor scope of coding-agent products: **Anthropic Claude Code, OpenAI Codex, Cursor, Google Gemini CLI, Antigravity, Hermes Agent, Qwen Code, and Grok Build**. Core exploit primitive: a malicious **`.git/config`** file uses **`core.fsmonitor`** (a Git performance setting whose value is a command Git runs to identify changed files) to **execute attacker code with the user's privileges, outside the AI agent's sandbox and without showing an approval prompt**. Timing-of-fire variations: on Claude Code and Hermes Agent, the payload fires *before the workspace-trust prompt is accepted*; on Qwen Code, *before the user has authenticated*; on Grok Build, *on the first keystroke*. Enterprise coding-agent procurement teams should treat sandbox integrity as a real vendor-scorecard item, not a checkbox item, and demand vendor-patch-latency SLA disclosure as a procurement requirement. (2) *The 50-day/30-release Anthropic patch latency is a real reputational cost that compounds against the same-day Amodei "Pace the Frontier" essay commitment to embedded evaluators* — if the internal safety-response pipeline takes 50 days to close a nine-vendor-scoped externally-disclosed sandbox escape, the credibility of the embedded-evaluator commitment depends heavily on whether METR-equivalent visibility gets access to the *incident-response and patch-latency* pipeline, not just the *training* pipeline. (3) *The `core.fsmonitor` primitive is a Git-configuration-surface issue, not an AI-model issue* — meaning the fix pattern is deterministic (config-file-parsing hardening + workspace-trust-boundary enforcement before any config-file read) and portable across vendors.

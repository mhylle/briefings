For enterprise architects, this is the first Tier-1 enterprise-SaaS vendor to make the agentic-control-plane an on-by-default default inside tenants that already licensed it. ## Counter-narrative

Skeptical case on the day's biggest story (**Salesforce Winter '27 Agentforce auto-enablement as a cadence step from opt-in to default-on**):

- **"Auto-enabled" ≠ "default-active." Agents still need deliberate configuration before they run anything in a given tenant.** The gate removed is the platform-infrastructure toggle, not the per-agent configuration gate. A tenant that had Agentforce "off" at the platform level and no configured agents is now "on" at the platform level but still has no configured agents — functionally unchanged. The headline "15 production-ready innovations shipped on by default" conflates platform-infrastructure default with per-agent-deployment default. Read the small print before writing memos.
